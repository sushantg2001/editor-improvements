# Editor Improvements

An Obsidian plugin in which one Lua keymap decides what every key does, on a Neovim-style vim engine.

- **One keymap for everything:** notes, the command palette, the file explorer, canvas and popout windows.
- **Any key can do anything:** run vim keys, an Obsidian command, copy or paste, or your own Lua function.
- **Vim in every editor:** notes, table cells and canvas cards.
- **You cannot get locked out:** press `Ctrl+Alt+Shift+F12` at any time to get Obsidian's own keys back.

Version 1.0.0 is for desktop. It has been tested on Linux.

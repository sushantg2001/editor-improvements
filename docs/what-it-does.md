# What it does today

Editor Improvements is at an early stage. It loads and unloads cleanly, and has no features yet. Turning it on changes nothing you can see.

## What stays the same

- **Your keys:** Obsidian's hotkeys and your vim setting keep working as before.
- **Your notes:** the plugin does not read or change them.
- **Your settings:** the plugin stores no settings or data.
- **Your screen:** it adds no commands, settings page, ribbon icon or status bar item.
- **Your privacy:** it makes no network requests.

## Where it has been tested

- **Obsidian:** 1.15.1. The minimum version is 1.15.0.
- **Linux:** tested with KDE Plasma.
- **macOS and Windows:** not tested yet.
- **Phones and tablets:** tested only in Obsidian's mobile emulation.
